# Roadmap

## v1.1 — Quick Wins (4 weeks post-launch)

- [ ] Streaming responses (SSE) for real-time chat feel
- [ ] Message search across all conversations
- [ ] Export conversations as PDF, Markdown, or JSON
- [ ] Keyboard shortcuts (Ctrl+K search, Ctrl+N new chat)
- [ ] Mobile app responsiveness improvements

## v1.2 — AI Enhancements (8 weeks post-launch)

- [ ] Agent swarm integration (DClaw Agent marketplace)
- [ ] Multi-modal input (image uploads for vision models)
- [ ] Smart memory: auto-summarize long conversations
- [ ] Custom system prompts per conversation
- [ ] RAG integration with DClaw RAG for document Q&A

## v2.0 — Platform (Q1 2027)

- [ ] Plugin ecosystem for custom AI providers
- [ ] Team workspaces with shared conversations
- [ ] Analytics dashboard (usage, costs, model performance)
- [ ] Enterprise SSO (SAML, OIDC)
- [ ] On-premise deployment package

## Under Consideration

- Voice mode (speech-to-text + text-to-speech)
- Code interpreter with sandboxed execution
- Collaborative editing (multiple users in one chat)
- Slack/Discord/Mattermost bots
